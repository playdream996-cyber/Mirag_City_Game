# Mirag City Game

Browser-first open-world action game prototype built with Babylon.js + TypeScript + Vite.

## Phase 1
- Third-person player controller
- Follow camera
- Stylized city blockout
- Roads and sidewalks
- Sprint movement
- Mission trigger hooks
- Wanted-system hooks
- Vehicle/NPC-ready architecture

## Run
```bash
npm install
npm run dev
```

## Controls
- `WASD` move
- `Shift` sprint
- Mouse orbit / zoom camera

## Roadmap
